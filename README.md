# Cellular Automaton Life Simulation (Java)

> An extended Game of Life simulation with several custom lifeforms, each with its own state-transition rules, colours and time-dependent behaviour.

🔒 **The source code is in a private repository** because this was university coursework at King's College London. I'm happy to walk through the code on request.

## Overview
Starting from a base cell simulation, I made the original lifeform follow Conway-style rules. I then designed and added several new lifeforms that interact on a shared 2D grid, visualised in a GUI with live statistics.

## What I built
- Conway-style birth, survival and death rules for the base lifeform
- Several custom lifeforms, each with its own transition behaviour, colour scheme and time-dependent dynamics
- A simulation loop, field statistics and a graphical view
- A short report documenting the design decisions and the challenge tasks I completed

Object-oriented design · inheritance and polymorphism · simulation · Java GUI
