# Cellular Automaton Life Simulation (Java)

> I extended Conway's Game of Life with new lifeforms, each with its own rules, colours and behaviour over time.

🔒 The code sits in a private repository because this was King's College London coursework. Ask me and I'll walk you through it.

## Overview
I took a basic cell simulation, gave its lifeform Conway-style rules, then designed new species that share the same 2D grid. A GUI draws the grid and shows live statistics.

## What I built
- Conway-style birth, survival and death rules for the base lifeform
- New lifeforms with their own transition rules, colours and time-based changes
- The simulation loop, field statistics and graphical view
- A short report on my design choices and the challenge tasks I finished
